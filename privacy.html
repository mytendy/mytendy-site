Privacy policy

Effective October 1, 2026. This policy covers the private mail utility that runs under this domain for its owner's own use. It has no users other than its owner.

What it accesses

The utility requests read-only access to the owner's Gmail account (the gmail.readonly scope). It cannot send, delete, move, label or alter anything in the account; the access it requests does not permit it.

What it keeps

Working files are kept on the owner's own computer. Raw mail is not retained after each run. Nothing is stored on any server operated under this domain, because there is none.

Google user data

The utility's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the utility's function to its owner. It is not sold, not used for advertising, not shared with third parties, and not read by any person other than the owner.

Control

The owner can revoke the utility's access at any time at myaccount.google.com/permissions and delete its working files.

Changes

If this policy changes, the new version is posted at this address with a new effective date.
